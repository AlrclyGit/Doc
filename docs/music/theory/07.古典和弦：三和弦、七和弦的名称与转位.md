# 古典和弦：三和弦、七和弦的名称与转位

## 三和弦

- 三和弦：由三个音按照三度叠置而成的和弦，英文为 Triad。
- 根音、三音、五音。
- 小三度 + 小三度 = 减三和弦 ($C_{○}$)。
- 小三度 + 大三度 = 小三和弦 ($C_{m}$)。
- 大三度 + 小三度 = 大三和弦 ($C_{△}$)。
- 大三度 + 大三度 = 增三和弦 ($C_{+}$)。

## 三和弦转位

- C 大三和弦第一转位，三音到五音为 3 度，三音到根音为 6 度。
- 写作：${C_{△}}_{ }^{6}$。读作：C 大六和弦。
- C 大三和弦第二转位，五音到根音为 4 度，五音到根音为 6 度。
- 写作：${C_{△}}_{4}^{6}$。读作：C 大四六和弦。

## 七和弦

- 七和弦：由三和弦加一个七音组成的和弦。
- 根音、三音、五音、七音。
- 大三和弦 + 大七度 = 大七和弦 (${C_{△}}_{ }7$)。
- 大三和弦 + 小七度 = 属七和弦 (${C7}$)。
- 小三和弦 + 小七度 = 小七和弦 (${C_{m}}_{ }7$)。
- 减三和弦 + 小七度 = 半减七和弦 (${C_{⌀}}_{ }7$）。
- 减三和弦 + 减七度 = 减七和弦 (${C_{○}}_{ }7$)。
- 小三和弦 + 大七度 = 小大七和弦。

## 七和弦转位

- C 大七和弦第一转位，三音到五音为 3 度，三音到七音为 5 度，三音到根音为 6 度。
- 写作：${C_{△}}_{5}^{6}$。读作：C 大六五和弦。

- C 大七和弦第二转位，五音到七音为 3 度，五音到根音为 4 度，五音到三音为 6 度。
- 写作：${C_{△}}_{3}^{4}$。读作：C 大四三和弦。

- C 大七和弦第三转位，七音到根音为 2 度，七音到三音为 4 度，七音到五 音为 6 度。
- 写作：${C_{△}}_{ }^{2}$。读作：C 大二和弦。
