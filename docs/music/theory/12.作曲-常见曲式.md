# 作曲：常见曲式

## 一、古典音乐常用曲式

### 1. 二段体 Binary

![2026-10-11-UEBMVv](https://cos.alrcly.com/2026-10-11-UEBMVv.jpg)

- 由 A、B 两段构成，通常每一段都单独反复。

调性 / 和声走向

| 段落 | 起止调性                             | 和声进行 |
| ---- | ------------------------------------ | -------- |
| A 段 | 从主调出发，结束时转到五级调（属调） | Ⅰ → Ⅴ    |
| B 段 | 从五级调出发，最终回归主调           | Ⅴ → Ⅰ    |

要点

- 二段体是最基础的入门曲式。
- 巴洛克时期巴赫的作品多为二段体。

### 2. 三段体 Ternary（ABA）

![2026-10-11-uohDXt](https://cos.alrcly.com/2026-10-11-uohDXt.jpg)

- 由 A 段、B 段、A′ 段（A 撇）组成，即 ABA 结构。

调性逻辑（以 C 大调为例）

| 段落 | 调性                    | 说明                       |
| ---- | ----------------------- | -------------------------- |
| A    | 主调（C 大调）          | 用主调创作                 |
| B    | 属调 / 五级调（G 大调） | 与 A 段形成对比            |
| A′   | 回归主调（C 大调）      | 再现开头内容，但需有所变化 |

要点

- 三段体是此后各种复杂曲式的基础原型，后续还可以在它之上继续发展。
- 凡是 ABA 这类曲式，第二个 A（A′）一定不能跟第一个 A 完全一样——完全重复会让观众觉得没劲；如同书法中一篇里出现三四个相同的字，书法家总会写得略有不同。

### 3. 奏鸣曲式 Sonata Form

![2026-10-11-uohDXt](https://cos.alrcly.com/2026-10-11-uohDXt.jpg)

- 奏鸣曲式在古典主义时期定型并发展完善，是最为常用的大型曲式，交响曲的第一乐章多采用这一结构。
- 三个核心部分：呈示部（Exposition）、发展部（Development）、再现部（Recapitulation）。
- 末尾可加一个无固定形式的尾声（Coda），板书中以 `*` 标注其为可选。

① 呈示部 Expo.：`Tm1 — Tr — Tm2`

| 组成          | 含义        | 调性                                           |
| ------------- | ----------- | ---------------------------------------------- |
| Tm1（主题一） | 第一主题    | 主调                                           |
| Tr（过渡段）  | 过渡 / 连接 | 引向第二主题                                   |
| Tm2（主题二） | 第二主题    | 大调作品转五级调（Ⅴ）；小调作品转关系大调（Ⅲ） |

② 发展部 Dev.

- 承接呈示部结束时的调性（板书中记作 `Ⅴ*` / `Ⅲ*`）。
- 对两个主题做各种各样的变奏、转调处理，也可以穿插新的内容。
- 调性变化灵活，以此丰富音乐层次。

③ 再现部 Rec.：`Tm1 — Tr — Tm2`

- 整体回归主调。
- 与呈示部最核心的区别：原本需要转调的第二主题，在再现部中也统一用主调，全曲最终在主调上收尾。

大调 / 小调和声走向对照

| 调式     | 呈示部 | 发展部   | 再现部 |
| -------- | ------ | -------- | ------ |
| 大调 Maj | Ⅰ → Ⅴ  | Ⅴ \*\*\* | Ⅰ → Ⅰ  |
| 小调 Min | ⅰ → Ⅲ  | Ⅲ \*\*\* | ⅰ → ⅰ  |

### 4. 回旋曲 Rondo Form

![2026-10-11-QclMd2](https://cos.alrcly.com/2026-10-11-QclMd2.jpg)

- 核心特征：A 段反复出现，每两个 A 段之间插入一个不同的对比段落。

回旋奏鸣曲式（复合曲式）

- 由回旋曲与奏鸣曲式组合、衍生而来。
- 从大框架看，可视为一个大三段体：两端的「ABA」是大 A，中间的「C」相当于发展部，即 大 A — 发展部 C — 大 A。

### 5. 变奏曲 Variation Form

![2026-10-11-QclMd2](https://cos.alrcly.com/2026-10-11-QclMd2.jpg)

- 以一个基础主题为核心，后续段落依次对主题做不同的变奏、不断翻新变化。
- 代表作品：莫扎特《小星星变奏曲》——其实际复杂度远超大众熟知的简易版《小星星》旋律。
- 变奏曲式与现代流行音乐关系密切：爵士乐最常用的就是变奏曲式——以固定的和弦进行为基础，乐手轮番即兴演绎，每一遍都形成一次变奏。

## 二、爵士乐常用曲式

### 1. 12 小节布鲁斯 12-Bar Blues

![2026-10-11-DVFmRt](https://cos.alrcly.com/2026-10-11-DVFmRt.jpg)

以 12 小节为一组循环，是爵士乐最标准的曲式之一。

- 全部采用属七和弦。
- 末尾的五级属七和弦（Ⅴ⁷）可以自然地衔接回下一遍开头的主和弦（Ⅰ⁷），因此能够无限循环演奏。

### 2. 32 小节 AABA 曲式 32-Bar Form

![2026-10-11-DVFmRt](https://cos.alrcly.com/2026-10-11-DVFmRt.jpg)

- 每 8 小节为一个段落，共 4 段，合计 32 小节。
- 前两段是相同的 A 段；第三段是具有对比性的 B 段，又称 Bridge（桥段）；第四段回归 A 段。
- 四段正好对应中国传统音乐理论里的「起 — 承 — 转 — 合」。

演奏中常见的问题

- 因为 A 段要反复多次，乐手很容易数错当前是第几遍 A，甚至提前进入 B 段，这是爵士乐现场很常见的状况。

## 三、流行音乐常用曲式 Song Form

![2026-10-11-ZUJW9f](https://cos.alrcly.com/2026-10-11-ZUJW9f.jpg)

俗称「流行歌」的 Song Form，并非只用于流行音乐，只是流行音乐普遍采用这一结构。

| 段落        | 英文                   | 特点                                                   |
| ----------- | ---------------------- | ------------------------------------------------------ |
| 前奏 / 引子 | Introduction（Intro.） | 乐曲开头的引入部分                                     |
| 主歌        | Verse（Ver.）          | 旋律固定，歌词变化，负责叙述                           |
| 副歌        | Chorus（Cho.）         | 歌词与旋律都固定、重复，是记忆点                       |
| 桥段        | Bridge（Br）           | 具有对比性、推动音乐发展；之后通常再接一遍副歌强化记忆 |
| 尾声        | Out（Outro）           | 乐曲收尾                                               |

核心特点

- 结构相对简单，但灵活性很高。
- 所有段落都是可选的，可以根据创作需要删减或重复，没有严格的强制规则。
