# 爵士和弦：拓展对和弦的认识

## 挂和弦

- 挂和弦：在三和弦中，使用二音或者四音替代三音的和弦。
- 根音、二音/四音、七音。
- 增四度 + 大二度 = 挂四和弦 (${C^{sus4}}$)。
- 大二度 + 增四度 = 挂二和弦 (${C^{sus2}}$)。

## 九和弦

- 九和弦：由七和弦加一个九音组成的和弦。
- 根音、三音、五音、七音、九音。
- 可以省略五音，但是一定要有七音。

## 十一和弦

- 九和弦：由九和弦加一个十一音组成的和弦。
- 根音、三音、五音、七音、九音、十一音。

## 十三和弦

- 九和弦：由十一和弦加一个十三音组成的和弦。
- 根音、三音、五音、七音、九音、十一音、十三音。

## 六和弦

- 六和弦：由三和弦加一个六音组成的和弦。
- 根音、三音、五音、六音、七音。

## 六九和弦

- 六和弦：由三和弦加一个六音、九音组成的和弦。
- 根音、三音、五音、六音、七音、九音。
