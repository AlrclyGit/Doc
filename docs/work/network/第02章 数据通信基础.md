# 第 02 章 数据通信基础

## 信道特性、奈奎斯特、香农定律

### 信道带宽

- 信道带宽：模拟信道中能够通过的频率范围
- 带宽公式：$W = f_2 - f_1$
  - $W$:信道带宽（频带宽度）; Hz（赫兹）
  - $f_2$:信道能通过的最高频率; Hz（赫兹）
  - $f_1$:信道能通过的最低频率; Hz（赫兹）

### 码元

- 码元：信号的一个基本波形、状态，是物理传输的最小信号单元，一个码元可以携带多个比特
- 码元速率（波特率）：单位时间内信道传送的码元个数
- 码元宽度：脉冲周期，模拟信号的宽度
- 码元速率公式：$B = \frac{1}{T}$
  - $B$:码元速率（波特率）; Baud（波特）
  - $T$:码元宽度（脉冲周期）; s（秒）
- 一个码元携带信息量：码元携带的比特数与码元种类数之间的关系
- 码元携带信息量公式：$n = \log_2 N$
  - $n$:一个码元携带的信息量; bit/码元
  - $N$:码元种类数（信号状态数）
    - QPSK 调制：$N = 4$
    - DPSK / BPSK 调制：$N = 2$

### 奈奎斯特定理

- 奈奎斯特定理：在一个理想的（没有噪声）信道中，信道带宽与最大码元速率之间的关系
- 最大码元速率公式：$B = 2W$
  - $B$:最大码元速率; Baud（波特）
  - $W$:信道带宽; Hz（赫兹）
- 极限数据速率公式：$R = Bn$
  - $R$:极限数据速率（比特率）; bit/s（bps）
  - $B$:最大码元速率; Baud（波特）
  - $n$:一个码元携带的信息量; bit/码元

### 香农定律

- 香农定律：在一个噪声信道的极限数据速率和带宽之间的关系
- 极限速率公式：$C = W \log_2 (1 + S/N)$
  - $C$:信道容量（极限速率），即理论上的最大无差错信息传输速率（比特率）; bit/s（bps）
  - $W$:信道带宽（频带宽度）; Hz（赫兹）
  - $S$:信号的平均功率; W（瓦）
  - $N$:噪声的平均功率; W（瓦）

### 信噪比

- 信噪比：信号的平均功率与噪声的平均功率之比
- 信噪比公式：$S/N$
  - $S/N$:信噪比，功率的比值（无单位）
  - $S$:信号的平均功率; W（瓦）
  - $N$:噪声的平均功率; W（瓦）
- 分贝与信噪比关系：信噪比的分贝表示，用于表示比值的大小
- 分贝公式：$\mathrm{dB} = 10\log_{10}(S/N)$
  - $\mathrm{dB}$:信噪比的分贝值; dB（分贝）
  - $S$:信号的平均功率; W（瓦）
  - $N$:噪声的平均功率; W（瓦）
  - 常用换算：$S/N = 1000$ 时，$\mathrm{dB} = 30$；$S/N = 100$ 时，$\mathrm{dB} = 20$
  - 注意：香农公式中的 $S/N$ 应代入功率比值，而非分贝值

### 误码率

- 误码率：表示传输二进制位时出现差错的概率
- 误码率公式：$P_c = \frac{N_e}{N}$
  - $P_c$:误码率，出错位数占传送位数的比例（无单位）
  - $N_e$:出错的位数; bit（比特）
  - $N$:传送的总位数; bit（比特）
- 误码率要求：计算机通信网络中，误码率一般要求低于 $10^{-6}$，即平均每传送 1 兆位才允许错 1 位
- 注意：误码率是概率值，与传输速率、信道带宽无关

## 信道延迟计算

### 信道延迟

- 信道延迟：数据从发送端传输到接收端所需要的总时间
- 信道延迟公式：$T = T_p + T_t$
  - $T$:信道延迟（总时延）; s（秒）
  - $T_p$:线路延迟（传播延迟）; s（秒）
  - $T_t$:发送延迟（传输延迟）; s（秒）

### 线路延迟

- 线路延迟（传播延迟）：信号在传输介质中传播所需要的时间，由传输距离和介质中的传播速度决定
- 线路延迟公式：$T_p = \frac{D}{V}$
  - $T_p$:线路延迟（传播延迟）; s（秒）
  - $D$:传输距离; m（米）
  - $V$:传播速度; m/s（米/秒）
- 特点：只与距离和介质有关，与数据帧大小、信道带宽（速率）无关

### 发送延迟

- 发送延迟（传输延迟）：把数据帧的全部比特发送到线路上所需要的时间
- 发送延迟公式：$T_t = \frac{L}{R}$
  - $T_t$:发送延迟（传输延迟）; s（秒）
  - $L$:数据帧大小（帧长）; bit（比特）
  - $R$:发送速率（比特率）; bit/s（bps）
- 特点：与帧长和发送速率有关，与传输距离无关
- 注意：计算前先统一单位，帧长由 B 换算为 bit（$\times 8$），速率换算为 bps

### 传播速度

- 传播速度：信号在介质中的传播速度由介质决定
- 光速：$V = 300000\mathrm{km/s} = 3 \times 10^{8}\mathrm{m/s} = 300\mathrm{m/\mu s}$
- 电缆：约为光速的 67%，即 $V = 200000\mathrm{km/s} = 2 \times 10^{8}\mathrm{m/s} = 200\mathrm{m/\mu s}$
- 单位换算：$1\mathrm{s} = 10^{3}\mathrm{ms} = 10^{6}\mathrm{\mu s}$、$1\mathrm{km} = 10^{3}\mathrm{m}$、$1\mathrm{B} = 8\mathrm{bit}$

### 常用数据

- 以太网最小帧长 64 B，最大帧长 1518 B，确认帧最小 64 B
- 以太网最大帧长 1518 B，其中包含 14 B 帧头 + 4 B 校验，故每个帧最多承载 IP 数据 1500 B = 12000 bit
- TCP 的序号是 32 位的，标示 $[0, 2^{32}-1]$ 的范围
- 卫星信道的时延大约 270ms（高时延信道，传播延迟远大于发送延迟）

## 传输介质

### 传输介质的分类

- 传输介质：把信号从一端传到另一端的物理通道
- 分类：有线介质和无线介质
  - 有线介质：双绞线、同轴电缆、光纤
  - 无线介质：无线电波、微波、红外线、激光
- 考试重点：看传播距离、带宽、抗干扰能力、成本和安装复杂度

### 无线电波频段

- $3\mathrm{Hz} \sim 30\mathrm{Hz}$：极低频（ELF），适合远程导航、水下通信
- $30\mathrm{Hz} \sim 300\mathrm{Hz}$：超低频（SLF），用于水下通信
- $3\mathrm{kHz} \sim 30\mathrm{MHz}$：低频~高频（LF~HF），常见于导航、短波通信
- $30\mathrm{MHz} \sim 300\mathrm{MHz}$：甚高频（VHF），电视、调频广播、雷达
- $300\mathrm{MHz} \sim 3\mathrm{GHz}$：特高频（UHF），电视、移动通信、卫星通信
- $3\mathrm{GHz} \sim 30\mathrm{GHz}$：超高频（SHF），微波中继、卫星通信、雷达
- $30\mathrm{GHz} \sim 300\mathrm{GHz}$：极高频（EHF），毫米波通信、卫星通信
- $>300\mathrm{GHz}$：红外、激光通信，通常用于光通信系统
- 微波：通常指 $300\mathrm{MHz} \sim 300\mathrm{GHz}$ 这一段，分为分米波、厘米波、毫米波
- 单位换算：$1\mathrm{kHz}=10^3\mathrm{Hz}$，$1\mathrm{MHz}=10^6\mathrm{Hz}$，$1\mathrm{GHz}=10^9\mathrm{Hz}$，$1\mathrm{THz}=10^{12}\mathrm{Hz}$

### 双绞线

- 双绞线：由多对绝缘铜导线两两缠绕而成，能降低电磁干扰
- 结构差异
  - UTP：非屏蔽双绞线，价格低，使用最广泛
  - STP：屏蔽双绞线，抗干扰更强，安装和成本都更高
- 网线常识
  - 100M 以太网：用 4 根线（2 对），即 1、2、3、6 四芯
  - 1000M 以太网：用 8 根线（4 对）全部使用
  - RJ45：网口接口；RJ11：电话接口
- 分类常识
  - Cat 5：可用于 100M，以前常见
  - Cat 5E / Cat 6：适合 1G 以太网
  - Cat 6A / Cat 7：适合 10G 以太网
  - Cat 8：用于服务器、数据中心，适合 25G/40G
- 口诀：低成本选 UTP，强干扰选 STP；百兆用 4 芯，千兆用 8 芯

| 介质 | 典型特点 | 适用场景 | 重点记忆 |
| ---- | -------- | -------- | -------- |
| 双绞线 | 便宜、易安装，抗干扰一般 | 局域网、布线 | 100M 用 4 芯，1G 用 8 芯 |
| 同轴电缆 | 抗干扰较好，带宽较大 | 有线电视、宽带、早期网络 | 常见于基带/宽带传输 |
| 光纤 | 衰减小、容量大、抗电磁干扰、距离远 | 骨干网、数据中心、长距离通信 | 单模长距离，多模短距离 |

### 同轴电缆

- 同轴电缆：由内导体、绝缘层、网状导体、外护层构成
- 基带同轴电缆：直接传输数字信号，常用于局域网
- 宽带同轴电缆：可同时传输多路模拟信号，常用于有线电视
- 特点：抗干扰性强于双绞线，价格高于双绞线，安装较复杂

### 光纤

- 光纤：利用光在光纤中全反射传输信息
- 基本特点：传输距离远、带宽大、容量大、衰减小、抗电磁干扰、体积小、重量轻
- 光纤结构：纤芯 → 包层 → 保护套
- 光缆结构：光纤 + 塑料外护套 + 增强层 + 填充结构
- 分类
  - 单模光纤：纤芯很细，仅允许一种模式传播，适合长距离、大容量，价格较高
  - 多模光纤：纤芯较粗，允许多种模式传播，适合短距离、低成本部署
- 常用波长
  - 多模：850nm、1300nm
  - 单模：1310nm、1550nm
- 典型光模块
  - SX：850nm，多模，最远约 550m
  - LX：1310nm，单模，最远约 10km
  - LH/ZX：1550nm，单模，最远约 10~120km
- 口诀：多模短距便宜，单模长距贵；单模配单模模块，多模配多模模块

| 类型 | 典型波长 | 适用距离 | 适用场景 |
| ---- | -------- | -------- | -------- |
| 多模光纤 | 850nm / 1300nm | 几十米到几公里 | 机房内、短距离连接 |
| 单模光纤 | 1310nm / 1550nm | 几公里到几十公里 | 骨干网、城域网、长距离通信 |

- 光纤接口常见类型：SC、LC、FC、ST
  - SC：方型接口，常见于光纤模块
  - LC：小型方型接口，网络设备最常用
  - FC：圆型接口，常用于配线架
  - ST：圆型卡口接口，常见于老设备
- 光纤跳线：带连接器的光纤线；
- 尾纤：单端带接口的光纤，用于熔接或连接
- 光纤连接方式：熔接和光纤连接器连接
