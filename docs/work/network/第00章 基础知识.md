# 基础知识

- 比特（b）：信息的最小单位，二进制的 0/1，也叫“位”
- 比特率：每秒传输的比特数; bit/s（bps）
- 字节（B）：8 比特为 1 字节，字节是数据存储的最小单位

指数运算

1、负指数幂：$a^{-n} = \frac{1}{a^n}$

2、分数指数幂：$a^{\frac{m}{n}} = \sqrt[n]{a^m}$

3、运算性质：

① $a^m \cdot a^n = a^{m+n}$ ；$\frac{a^m}{a^n} = a^{m-n}$ ；

② $(a^m)^n = a^{mn}$ ；

③ $(ab)^m = a^m b^m$ ；$(\frac{a}{b})^m = \frac{a^m}{b^m}$ 。
