# 第 01 章 计算机网络概论

## OSI 和 TCPIP 参考模型

### 模型对比

| OSI 七层网络模型 | 五层网络模型 | TCP/IP 四层网络模型   |
| ---------------- | ------------ | --------------------- |
| 应用层           | 应用层       | 应用层                |
| 表示层           | 应用层       | 应用层                |
| 会话层           | 应用层       | 应用层                |
| 传输层           | 传输层       | 传输层                |
| 网络层           | 网络层       | 网络层                |
| 数据链路层       | 数据链路层   | 网络接口层/网际接入层 |
| 物理层           | 物理层       | 网络接口层/网际接入层 |

### 模型各层主要功能

| OSI 七层网络模型 | 各层主要功能                                     |
| ---------------- | ------------------------------------------------ |
| 应用层           | 各种应用程序、协议                               |
| 表示层           | 数据和信息的语法转换内码，数据压缩解压、加密解密 |
| 会话层           | 为通信双方指定通信方式，并创建、注销会话         |
| 传输层           | 提供可靠或者不可靠的端到端传输                   |
| 网络层           | **逻辑寻址；路由选择**                           |
| 数据链路层       | 数据链路层                                       |
| 物理层           | 在媒介上传输比特流；提供机械和电气规约           |

### 模型各层协议

| OSI 七层网络模型 | 网络协议                                         |
| ---------------- | ------------------------------------------------ |
| 应用层           | Telnet, HTTP, FTP, SMTP, TFTP, NFS, SNMP, DHCP   |
| 表示层           | Telnet, HTTP, FTP, SMTP, TFTP, NFS, SNMP, DHCP   |
| 会话层           | Telnet, HTTP, FTP, SMTP, TFTP, NFS, SNMP, DHCP   |
| 传输层           | TCP, UDP                                         |
| 网络层           | ICMP, Routing Protocol（静态、RIP、OSPF 等）, IP |
| 数据链路层       | Ethernet, Frame-Relay, PPP/PPPOE, HDLC           |
| 物理层           | 双绞线，光纤，跳线/尾纤，配线架/理线架           |

## 数据封装与解封过程

| OSI 七层网络模型 | 数据单元构成          | PDU 名称           | 地址（标识） |
| ---------------- | --------------------- | ------------------ | ------------ |
| 应用层           | 数据                  | APDU               | 进程号       |
| 表示层           | 数据                  | APDU               | 进程号       |
| 会话层           | 数据                  | APDU               | 进程号       |
| 传输层           | TCP 报头/数据         | 数据段/报 Segment  | 端口号       |
| 网络层           | IP 报头，负载，FCS    | 数据包/分组 Packet | IP 地址      |
| 数据链路层       | 以太网报头，负载，FCS | 数据帧 Frame       | MAC 地址     |
| 物理层           | 1010101               | 比特流 Bit         |              |
